# 工作区 UI

## ADDED Requirements

### Requirement: 消息转换菜单

系统 **MUST** 在聊天面板的消息项上提供转换操作入口。

#### Scenario: 显示消息操作菜单
- **WHEN** 用户悬停在聊天消息上
- **THEN** 消息右侧显示更多操作按钮（三点图标）
- **AND** 点击按钮展开操作菜单
- **AND** 菜单包含"转为笔记"和"转为来源"选项

#### Scenario: 转为笔记子菜单
- **WHEN** 用户悬停在"转为笔记"菜单项
- **THEN** 展开子菜单显示可用的输出类型
- **AND** 包含：段落、要点、结构化 等选项
- **AND** 用户点击选项后触发转换

#### Scenario: 转为来源操作
- **WHEN** 用户点击"转为来源"菜单项
- **THEN** 系统开始转换流程
- **AND** 显示加载状态指示器
- **AND** 完成后显示成功通知

### Requirement: 会话级转换入口

系统 **MUST** 提供将整个会话转换为来源或笔记的入口。

#### Scenario: 会话转换按钮
- **WHEN** 用户在聊天面板标题区域
- **THEN** 显示会话转换按钮或菜单入口
- **AND** 点击后可选择转换目标类型
- **AND** 支持转换为来源或笔记

### Requirement: 转换状态反馈

系统 **MUST** 在转换过程中提供清晰的状态反馈。

#### Scenario: 转换进行中
- **WHEN** 转换操作正在执行
- **THEN** 显示加载指示器（Spinner）
- **AND** 禁用重复操作
- **AND** 用户可以继续其他操作（非阻塞）

#### Scenario: 转换成功
- **WHEN** 转换操作完成
- **THEN** 显示成功通知（toast）
- **AND** 如果转为来源，来源列表自动刷新
- **AND** 如果转为笔记，笔记列表自动刷新

#### Scenario: 转换失败
- **WHEN** 转换操作失败
- **THEN** 显示错误通知，包含简要错误信息
- **AND** 提供重试选项

### Requirement: Studio 面板笔记项交互

系统 **MUST** 确保 Studio 面板中笔记项的交互元素可正常点击。

#### Scenario: 笔记项主区域点击
- **WHEN** 用户点击笔记项的主要区域（图标、标题、元信息）
- **THEN** 打开笔记详情查看器
- **AND** 不触发菜单展开

#### Scenario: 笔记项菜单按钮点击
- **WHEN** 用户点击笔记项右侧的更多操作按钮
- **THEN** 展开操作菜单
- **AND** 不触发笔记详情查看器
- **AND** 菜单包含"转换为来源"、"复制内容"、"删除"选项

#### Scenario: 菜单按钮悬停显示
- **WHEN** 用户悬停在笔记项上
- **THEN** 更多操作按钮变为可见
- **AND** 按钮点击区域足够大（至少 24x24 像素）
- **AND** 移动端触摸区域响应正常
