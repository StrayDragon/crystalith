# 跨文档分析图谱视图优化

## 背景

当前的跨文档分析功能使用列表/卡片形式展示主题聚类、来源关联和矛盾检测结果，实用性有限。用户希望有类似 Obsidian 知识图谱的可视化交互体验。

## 目标

将跨文档分析从静态列表视图改为基于 ReactFlow 的全屏交互式知识图谱，提供更直观的来源关联可视化。

## 方案

1. **全屏图谱覆盖** - 点击按钮后图谱覆盖整个工作区
2. **节点展示** - 每个来源作为一个节点，颜色根据主题聚类分配
3. **边展示** - 显示来源之间的关联（粗细/透明度表示强度）
4. **交互功能**：
   - 缩放、平移、拖拽节点
   - 悬停显示来源信息
   - 点击节点选中并显示详情
   - 矛盾节点红色高亮标记
