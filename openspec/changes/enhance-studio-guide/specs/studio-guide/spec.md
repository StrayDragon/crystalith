## ADDED Requirements

### Requirement: 交互式学习路径

系统 **MUST** 将指南呈现为可交互的学习路径，支持进度追踪。

#### Scenario: 显示学习模块

- **WHEN** 用户打开指南
- **THEN** 每个模块显示为可折叠的卡片
- **AND** 卡片包含完成勾选框、预估时间、进度指示

#### Scenario: 标记模块完成

- **WHEN** 用户勾选模块的完成框
- **THEN** 模块显示为已完成状态
- **AND** 整体进度条更新

### Requirement: 模块依赖关系

系统 **MUST** 支持模块间的前置依赖关系。

#### Scenario: 锁定未解锁模块

- **WHEN** 模块有未完成的前置依赖
- **THEN** 该模块显示为锁定状态
- **AND** 显示需要先完成的模块列表

#### Scenario: 解锁模块

- **WHEN** 用户完成所有前置模块
- **THEN** 依赖模块自动解锁
- **AND** 显示解锁动画

### Requirement: 学习笔记

系统 **MUST** 支持在指南中添加个人笔记。

#### Scenario: 添加行内笔记

- **WHEN** 用户在某个要点旁点击笔记图标
- **THEN** 显示笔记输入框
- **AND** 笔记支持 Markdown 格式

#### Scenario: 查看所有笔记

- **WHEN** 用户点击笔记列表按钮
- **THEN** 显示当前指南中所有笔记的汇总视图

### Requirement: 检查点测验

系统 **MUST** 在关键学习节点插入检查点测验。

#### Scenario: 显示检查点

- **WHEN** 用户完成一个模块
- **THEN** 如果该模块有检查点，显示测验弹窗
- **AND** 用户必须通过测验才能继续
