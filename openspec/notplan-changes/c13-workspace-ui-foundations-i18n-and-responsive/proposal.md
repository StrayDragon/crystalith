## Why

Workspace 目前在两个基础维度上限制了可用性与可扩展性：

- **移动端可用性不足**：三栏布局在手机/平板上容易挤压到不可用，触摸交互缺少针对性优化。
- **文案不可扩展**：用户可见字符串分散在组件中，难以统一管理与演进；也无法在需要时提供多语言。

这两个问题都属于 UI 基础能力，适合合并为同一个提案与同一个 change：先把“能用、可维护、可扩展”的底座打稳，再做更上层的功能。

## What Changes

- 响应式布局与移动端导航：
  - 在移动端窄屏下使用单面板模式（Sources/Chat/Studio）+ 底部 TabBar 切换
  - 定义移动/平板断点，并补齐面板切换动画与状态保留边界
  - 触摸优化（点击目标、滚动/hover 策略）与可选滑动手势切换
  - 对话框在移动端采用全屏/近全屏形态，避免内容被遮挡
- 本地化与 i18n 扩展：
  - 引入集中化的 message key + `t()`（或等价）接口，逐步移除关键路径硬编码字符串
  - 在保持默认 `zh-CN` 的前提下，支持可选的 `en-US` locale 与语言切换入口
  - 日期/时间/数字/相对时间等格式化遵循当前 locale

## Impact

- 受影响的规范：`workspace-ui-core`（MODIFIED）
- 受影响的代码（预期）：
  - `frontend/web/src/features/workspace/**`（移动端布局与交互）
  - `frontend/web/src/i18n/**`（新增本地化模块与资源文件）
  - 多数前端组件（字符串提取与格式化）
