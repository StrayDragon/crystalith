## Why

当前系统无用户认证机制，所有数据对所有访问者公开。这在多用户、团队使用或公网部署场景下存在安全风险。引入用户认证系统是支持多用户功能（协作、权限）的前置条件。

## What Changes

- 实现用户注册和登录（邮箱+密码）
- 基于 JWT 的会话管理
- API 端点添加认证中间件
- 前端添加登录/注册页面
- 数据隔离：每个用户只能访问自己的 notebook（或被共享的）
- 支持可选的匿名模式（单用户部署时禁用认证）

## Impact

- 受影响的规范：新增 `user-auth`，`workspace-ui`（MODIFIED）
- 受影响的系统：
  - 后端所有 API 端点（添加认证中间件）
  - 数据库 schema（用户表、notebook 所有者字段）
  - 前端路由（添加认证路由守卫）
  - 配置文件（认证相关配置项）
