# 问答（QA）

RAG 对话核心：预设、同步/流式问答、导出。

---

### `qa-presets-list`

- **Domain:** qa
- **Route:** `GET /v2/qa/presets`
- **说明:** 列出内置 QA 预设（default/analysis/creative/explainer/stats）
- **用户可见:** Partial
- **代码:** `apps/server/src/features/qa/router.ts`、`qa/presets.ts`

> NOTE: 待盘点

---

### `qa-ask`

- **Domain:** qa
- **Route:** `POST /v2/qa`
- **说明:** 非流式 RAG 问答；支持 preset、directive、source_ids、retrieveSources tool
- **用户可见:** Partial（主路径为 stream）
- **代码:** `apps/server/src/features/qa/router.ts`、`qa/handler.ts`

> NOTE: 待盘点

---

### `qa-stream`

- **Domain:** qa
- **Route:** `POST /v2/qa/stream`
- **说明:** SSE 流式 RAG 问答；写入 assistant message
- **用户可见:** Yes
- **代码:** `apps/server/src/features/qa/router.ts`、`qa/handler.ts`

> NOTE: 待盘点

---

### `qa-export`

- **Domain:** qa
- **Route:** `GET /v2/qa/export`
- **说明:** 导出会话 QA（Markdown/JSON，含 citations）；query: `notebook_id`, `session_id`, `format`
- **用户可见:** Yes
- **代码:** `apps/server/src/features/qa/router.ts`
