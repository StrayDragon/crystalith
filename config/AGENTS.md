# config — Crystalith v2 Runtime Configuration

> Runtime/business config lives in `config/app.yaml` (SSOT).
> Secrets go in `config/secret.env` (gitignored).

## v2 Changes from v1

| v1 (Python) | v2 (Bun/TS) |
|-------------|-------------|
| Jinja2 template rendering | Nunjucks (same `{{ }}` syntax) |
| Pydantic Settings validation | Zod schema validation |
| Config schema generated by `just config-schema` | Manual Zod schema (simpler, no codegen) |
| Overlay system (app.local.yaml, app.{env}.yaml) | Removed — single `app.yaml` covers local + desktop |
| `endpoint_candidates` auto-discovery | Removed — static localhost for desktop app |

## Key Config Paths (v2)

- `app.server.port` — HTTP listen port (default: 8032)
- `app.models.*` — LLM model configurations (provider + modelId)
- `app.database.path` — SQLite database file path
- `app.rag.*` — RAG strategy configurations
- `app.source_ingestion.*` — PDF/HTML/URL extraction settings

## Template Variables

`config/app.yaml` supports `{{ env.KEY }}` and `{{ secret.KEY }}` placeholders:
- `env.*` — from environment variables (`.env` overrides)
- `secret.*` — from `config/secret.env`

Example:
```yaml
models:
  default:
    provider: openai
    api_key: "{{ secret.OPENAI_API_KEY }}"
    base_url: "{{ env.OPENAI_BASE_URL }}"
```

## File Layout

```
config/
├── app.yaml              # SSOT — runtime/business config (Nunjucks templates)
├── secret.env            # Secrets (gitignored)
└── secret.env.example    # Template for secret.env
```
