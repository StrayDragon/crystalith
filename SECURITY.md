# Security Policy

## Supported Versions

We provide security fixes for the latest `main` branch only.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security reports.

Preferred:
- Open a GitHub Security Advisory: **Security** → **Report a vulnerability**.

Alternative (if you cannot use advisories):
- Email: `straydragonl@foxmail.com` (use subject prefix `[SECURITY]`).

Please include:
- A clear description of the issue and potential impact
- Steps to reproduce (ideally a minimal PoC)
- Affected version/commit and environment (local dev vs Docker Compose)
- Any relevant logs or screenshots (redact secrets)

## What Not To Share Publicly

- API keys, tokens, or secrets files
- Private URLs, credentials, or personal data
- Exploit details before a coordinated fix is available

## Response Expectations

We aim to acknowledge reports within 7 days and provide a remediation plan or status update as soon as practical.
