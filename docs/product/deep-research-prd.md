## 1. 一句话定位

**Deep Research** 是 Crystalith 的**原子化研究运行时** + **顶栏调研入口**：主控 Agent 驱动「拆解 → 调研 → 证据 → 报告」，以可 checkpoint 的 **xyflow DAG** 为过程态、以**章节引用报告**为结果态；用户从**顶栏搜索/输入**进入二级深研台（队列与操作），并可将**研究过程中任一步骤**转化为**来源或笔记**，从而让**对话**能对结果做稳定 RAG（chat with result）。

---

## 2. 背景与问题

### 2.1 旧实现的问题（已 stub）

- 单体 for-loop + DB 轮询 HITL，不可组合、难调试。
- 深研入口挤在「来源」搜索模式里，模糊了「入库」与「长程调研」的边界。
- 过程不可视；产物与来源/笔记/对话脱节，难以「聊研究结果」。

### 2.2 信息架构问题（v0.2 新增）

当前三栏（来源 / 笔记 / 对话）本是清晰流水线，但**网页搜索框嵌在来源栏**会：

- 占用来源栏心智（管理库 vs 往外搜）；
- 与「整本笔记检索」等未来能力抢同一位置；
- 把 Deep Research 误绑成「搜索的一种模式」，而不是可产出可转化的任务系统。

### 2.3 产品机会

1. **顶栏 = 统一检索/调研入口**（习惯位；可演进为 notebook 内搜索）。
2. **可见过程**（节点图）+ **可信结果**（章节引用报告）。
3. **可选知识边界**（用已有来源，或 Agent 自研）。
4. **原子工具共享**（SearXNG / RAG / 笔记读写）。
5. **有机转化**：深研任一步 → 来源或笔记 → 对话可 RAG。

## 4. 产品原则

1. **三栏干净**：来源=库，笔记=文档产物，对话=问答；深研是顶栏驱动的**跨栏生产线**。
2. **Atomic by default**：能力先成 tool，再被主控编排。
3. **Optional everything**：已选来源、笔记上下文、外网、先前报告——均可关。
4. **Process + Result**：图与报告都是一等产物；转化是桥梁，不是替代 Run SSOT。
5. **Evidence over verbosity**：无证据 → `missing`；转化到来源/笔记时带上证据溯源。
6. **Checkpoint-first**：长任务可恢复。
7. **Chat with result**：凡转化进库的文档/来源，必须可被现有 RAG/对话路径消费（chunk + embed 或等价）。

## 5. 工作区信息架构（v0.2 核心）

```text
┌──────────────────────── 顶栏 ────────────────────────┐
│  [Notebook ▾]     【 统一输入 / 搜索 】      [锁] [用户] │
│                      │                                │
│         单击/聚焦 ───┼──→ 二级页：深研台               │
│                      │    · 快速：网搜添加来源（默认）   │
│                      │    · 深度：配置 + 队列 + 任务    │
│                      │    · 以后：整本笔记搜索          │
└──────────────────────┼────────────────────────────────┘
                       │
     ┌─────────────────┼─────────────────┐
     ▼                 ▼                 ▼
  ┌──────┐         ┌──────┐         ┌──────┐
  │ 来源  │         │ 笔记  │         │ 对话  │
  │ 库管理 │         │ 文档  │         │ RAG   │
  │ 列表  │◄─转化───│ 列表  │◄─转化───│ chat  │
  │      │         │      │  with    │ result│
  └──────┘         └──────┘  result  └──────┘
                       ▲
                       │ ResearchRun（SSOT：图+报告+checkpoint）
                       │ 二级页打开 / 管理队列
```

### 5.1 顶栏输入（前置交付）

| 模式           | 首发         | 行为                                                              |
| -------------- | ------------ | ----------------------------------------------------------------- |
| **网搜添来源** | ✅           | 等价迁出原来源栏搜索：查 SearXNG → 选结果 → 入库（Fast Research） |
| **深度研究**   | ✅（二级页） | 进入深研台：新任务配置、队列、打开某 Run 活视图                   |
| **整本搜索**   | ⏳ 占位      | UI 可露入口/segment，后端可后接                                   |

**UI 迁移范围（G0）**：

- 从来源栏移除主搜索条（或降为次要筛选「过滤已有来源」）。
- 顶栏中置输入：placeholder 区分「搜索网络添加来源 / 深度研究…」。
- 交互：点击输入框 → 展开二级页（面板/抽屉/路由均可，需符合 Layer 系统）。

### 5.2 深研二级页（主入口）

二级页至少包含：

1. **新任务配置**：问题、是否用已选来源、是否外网、深度档位、模型…
2. **队列 / 历史**：本 notebook 的 `ResearchRun` 列表（进行中置顶）。
3. **活任务态**：研究中 / 待确认 / 失败 / 已完成。
4. **操作**：暂停、继续、取消、打开图、打开报告、**转化为来源/笔记**。
5. （可选）需要确认时的确认条（例如批准继续某一支路）——轻量，非旧 DB 轮询 HITL。

打开某个 Run 后进入**完成/过程卡片式详情**：xyflow + 报告入口 + 转化菜单（对齐你提的「点配置后直接进入卡片并提示状态」）。

### 5.3 三栏如何变干净

| 栏       | 做什么                                                       | 不做什么                             |
| -------- | ------------------------------------------------------------ | ------------------------------------ |
| **来源** | 添加（URL/上传/连接器）、列表、索引状态、选择供 RAG/深研约束 | 不再承载网页主搜索条；不做深研主入口 |
| **笔记** | 展示已转化的文档笔记、其它生成物                             | 不强制深研自动写入                   |
| **对话** | 对已选/全库来源与（转化后的）笔记做问答                      | 首发不承载深研编排壳                 |

## 7. 领域模型（要点）

| 对象                          | 说明                                                                                      |
| ----------------------------- | ----------------------------------------------------------------------------------------- |
| `ResearchRun`                 | SSOT：配置、状态、checkpoint、notebookId                                                  |
| `ResearchGraph` / Node / Edge | 过程图；节点可挂 `evidenceIds`                                                            |
| `Evidence`                    | web / source chunk / note / prior report                                                  |
| `ResearchReport`              | 正文 + citation map + 章节索引                                                            |
| `Conversion`                  | 显式动作：`artifactRef` → Source 或 Output(Note)，写入 `derivedFromRunId` + 可选 `nodeId` |

**转化（G7）粒度（产品要求）**：

| 可转化对象          | → 来源        | → 笔记                                    |
| ------------------- | ------------- | ----------------------------------------- |
| 单条 web 证据 / URL | ✅ 抓取入库   | ✅ 摘录笔记                               |
| 节点结论 + 证据包   | ✅ 合并文档源 | ✅ 结构化笔记                             |
| 阶段报告 / 终稿     | ✅ 全文源     | ✅ 文档笔记（章节引用可降级为文末或保留） |

转化后：**必须进入可嵌入索引的路径**，对话才能 chat with result。

## 8. 主控 Agent（摘要）

- 主控只编排；工具原子化（共享 `webSearch`，禁止深研内再实现一份 SearXNG）。
- Checkpoint 每步或每 N 节点。
- 用户介入：配置、暂停/取消、轻量确认、**转化**；旧式「审批整份 search plan」不默认回归。
